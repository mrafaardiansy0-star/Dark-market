# 🌶️ Dark Market

Marketplace + Real-time Chat. Simulasi dark web untuk edukasi.

## Fitur

- ✅ Register / Login (JWT)
- ✅ Marketplace (jual/beli produk)
- ✅ Real-time chat (WebSocket)
- ✅ Wallet system
- ✅ Order system
- ✅ SQLite database

## Stack

- **Backend:** Python 3.10+, FastAPI, WebSocket, SQLite
- **Frontend:** HTML/CSS/JS (vanilla)
- **Auth:** JWT
- **Realtime:** WebSocket
